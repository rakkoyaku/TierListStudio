# TierListStudio

キャラクターのアイコンをドラッグして並べ、**ティア表**・**アライメント表**・**2 軸マップ**を作る Windows / macOS 用の無料アプリです。[TachieKara](https://github.com/rakkoyaku/TachieKara)・[SeKurabe](https://github.com/rakkoyaku/SeKurabe) の姉妹アプリです。

- アイコンの画像をフォルダごとドロップするだけで、ファイル名がそのままキャラの名前になります。名前・メモ・タグを付けておけば、だれが誰だか迷いません。
- 一度入れたキャラ（キャラ帳）は、好感度表・強さ表・アライメント表…と、何枚のボードでも使い回せます。
- ドラッグすると周りのアイコンがよけて、差し込む場所が見えます。複数をまとめて動かしたり、数字キーで段へ送ったり、元に戻したりもできます。
- 書き出す画像は、画面で見たままです。×2〜×4 の大きさで書き出せるので、SNS に載せても粗くなりにくくなっています。クリップボードへのコピーもできます。

> **作った画像の権利について**
> 作った画像に含まれる絵の権利は、元のアイコンの作者・権利者のものです。TierListStudio を使っても元の権利は損なわれず、TierListStudio の作者は作った画像に何の権利も主張しません。作った画像は、元の絵の権利者が認める範囲で使ってください。

## ダウンロードとインストール

[Releases](https://github.com/rakkoyaku/TierListStudio/releases/latest) から OS に合ったものを取ってください。

| OS | ファイル |
|---|---|
| Windows | `TierListStudio-win-Setup.exe`（インストール版）／ `TierListStudio-win-Portable.zip`（展開して使う版） |
| macOS（Apple Silicon: M1 以降） | `TierListStudio-osx-arm64-Portable.zip` |
| macOS（Intel） | `TierListStudio-osx-x64-Portable.zip` |

### Windows

`TierListStudio-win-Setup.exe` を実行するとインストールされ、スタートメニューとデスクトップにショートカットができます。
署名をしていないため「Windows によって PC が保護されました」と出た場合は、［詳細情報］→［実行］を押してください。

### macOS

> macOS 版は現在、実機での動作確認を進めているところです。うまく動かない場合は Issues で教えてください。

Apple の公証を受けていないため、初回は「開発元を確認できない」と表示されます。

1. zip を展開し、`TierListStudio.app` を「アプリケーション」へ移動します。
2. 一度ダブルクリックして警告を閉じます。
3. 「システム設定」→「プライバシーとセキュリティ」の下部にある「このまま開く」を押します。

ターミナルで `xattr -dr com.apple.quarantine /Applications/TierListStudio.app` を実行しても開けるようになります。

## 使い方

1. **アイコンを入れる** — 画像やフォルダをウィンドウにドロップします（PNG・JPG・WebP・BMP）。正方形でない画像は、自動で正方形に切り抜きます（縦長なら上寄り）。段やマスの上に落とすと、そのままそこへ置かれます。
2. **並べる** — 下の置き場から、段・マスへドラッグします。置き場へ戻すと表から外れます。
3. **整える** — 右のパネルで、タイトル・段の型・色の組み合わせ・アイコンの大きさ・名前の出し方・フォントなどを変えます。見出し（段の名前）の幅は文字に合わせて自動で決まりますが、見出しの右端をドラッグして変えることもできます（右端のダブルクリックで自動に戻ります）。
4. **書き出す** — 右下の［画像を書き出す］で PNG / JPG に保存します。隣のボタンでクリップボードにコピーできます。

### 画像から再現する

書き出した画像には、標準で **並びの情報** が入ります（画像の見た目は変わりません）。受け取った人がその画像をウィンドウにドロップすると、自分のキャラ帳のキャラで同じボードを作れます（左上の［＋］→「画像から再現…」からも）。

- キャラは名前で照らし合わせます。見つからないキャラは、自分のキャラに当てるか、画像から切り抜いた **仮のアイコン** で置くか、置かないかを選べます。仮のアイコンは、あとで自分の画像に差し替えられます。
- 入るのは段・マス・軸の名前と色、置いた場所、見た目の設定、キャラの名前です。画像の場所（フォルダ名）は入りません。メモ・タグは「キャラのメモ・タグも入れる」を選んだときだけ入ります。入れたくないときは、「書き出す画像」の「並びの情報を画像に入れる」を外してください。
- SNS に投稿したり、クリップボードにコピーして貼り付けたりすると、情報が消えることがあります。ファイルのまま渡すのが確実です。

### ボードの種類

左上の［＋］で増やせます。キャラ帳は全部のボードで共通です。

- **ティア表** — 段の型（S〜D・S〜F・SS〜D・好感度・推し度・〇〇しそう・1〜5）と、自分で作って保存した型。段は追加・削除・見出しのドラッグで並べ替えができます。
- **表** — 行 × 列のマスに置きます。アライメント 3×3・2×2・3×3・曜日の型があり、行・列は自由に増やせます。
- **2 軸マップ** — 縦横の軸に名前を付けて、自由な位置に置きます。中心の線やほかのキャラの縦・横の位置に吸い付きます（Alt で無効）。

「〇〇から見た好感度」のように、タイトルの横にキャラのアイコンを出すこともできます。

### 操作

| 操作 | できること |
|---|---|
| ドラッグ | 段・マス・置き場のあいだで動かす（複数選んでまとめても） |
| Ctrl / Shift＋クリック、何もない所をドラッグ | 複数を選ぶ |
| 1〜9 / 0 | 選んだキャラを 1〜9 段目へ送る / 置き場へ戻す |
| ← → ↑ ↓ | となりと入れ替える・上下の段へ動かす（マップでは少しずつ動かす） |
| Delete | 置き場へ戻す |
| ダブルクリック | キャラなら名前・メモの編集、見出しやタイトルならその場で書き換え |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+ホイール | 拡大・縮小（置き場ではアイコンの大きさ） |
| Ctrl+S | プロジェクトを保存 |

作業はプロジェクト（`.tierlist`）として保存できます（左上のメニュー）。画像そのものは入らず、画像の場所を覚えておく形です。最後の作業は、次に起動したとき自動で戻ります。

## アップデート

インストールしたアプリは、起動時に新しいバージョンがないか確認します。左上の **ⓘ（ソフトウェア情報）** からも確認できます。

1. 新しいバージョンがあると、左上に「新しいバージョン x.y.z があります」と出るので［ダウンロード］を押します。
2. ダウンロードが終わると、**次にアプリを起動したときに反映** されます。すぐに反映したいときは［今すぐ再起動］を押してください。

起動時の確認は、ソフトウェア情報の「起動時に新しいバージョンを確認する」で止められます。

## 通信とデータについて

- TierListStudio がインターネットに接続するのは、**新しいバージョンの確認とダウンロード（GitHub）だけ**です。読み込んだ画像や作った画像を送ることはなく、利用状況の収集もしていません。
- 最後の作業とアプリの設定（保存した段の型など）は、このパソコンの中だけに保存します。
  - Windows: `%APPDATA%\TierListStudio\`
  - macOS: `~/.config/TierListStudio/`

## 困ったときは

- アプリが落ちた場合は、上のフォルダにある `crash.log` に原因が記録されます。
- 不具合の報告や要望は [Issues](https://github.com/rakkoyaku/TierListStudio/issues) へどうぞ。
